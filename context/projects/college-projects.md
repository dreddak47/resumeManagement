These are the 4 college-era projects currently listed in the resume template. Deep exploration not required (per user instruction — GitHub has them, low ongoing relevance), but keeping the resume-facing summary here for consistency and quick reference.

## Anumaan (Aug 2024 – Jan 2025)
Full-stack app (React, Node.js, Flask, Cloud, MLOps) built for IITK research on "Assessing Cognitive Immersion in Online Exams" — analyzing guessing behavior via live click interactions, Facial Action Units, and gaze tracking. Processed data from 50+ test participants. Has a public write-up/blog.

## StockWorthy (Sept 2024)
AI agent project: RAG pipeline combining real-time sentiment analysis with structured financial metrics for short-term stock trend prediction (resume claims R²=0.85). Fine-tuned Microsoft phi-2 on a Hugging Face dataset for sentiment analysis (F1 0.7, claimed +10% over baseline). Has a GitHub link in resume.

## Real-time Face Recognition System (June 2024)
AWS SageMaker-based face recognition pipeline (~92% accuracy), modular ML model deployment, multithreaded video capture, model quantization + lazy loading + EC2 horizontal scaling (~80ms inference reduction claimed).

## Sentiment Analysis Across Languages (NLP course paper)
Transformer-based evaluation of sentiment analysis performance across multilingual/machine-translated text, covering 6 major non-English languages. This is the NLP-course paper referenced in `profile.md` — a real, published/written paper, distinct from the MIDAS Lab research work.
