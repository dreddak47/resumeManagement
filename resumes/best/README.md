# Best-scoring snapshots

Whenever an optimization round on any resume variant produces a fresh, neutral scorer result with **Fit score > 90** (ATS score can be anything), the `.tex` (and compiled `.pdf`) is copied here as `<variant>_fit<score>_<date>.tex` before further edits continue. This preserves high-scoring versions even if a later edit regresses the score.

No snapshot has qualified yet as of 2026-09-17 — best result so far for `sde.tex` is ATS 92 / Fit 88 (not >90 on Fit).
